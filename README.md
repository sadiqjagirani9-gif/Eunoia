# Eunoia

**本地优先的 AI 交流客户端。** 在六个独立人格空间中对话，或进入单独的倾听空间。模型由你接入，数据由你掌控。

## 核心功能

- 六人格：Evelyn 情感解剖、Arthur 理性辩论、Sophia 生活指导、Iris 自我探索、Lucien 文学艺术、Felix 日常闲谈。各自拥有独立的提示词、对话、记忆和知识库。
- Haven 倾听空间：专注倾听与支持；独立保存对话和用户主动添加的记忆，不参与认知画像或联合会诊。
- 自带模型：支持 OpenAI Compatible、Anthropic 和本地 Ollama。可为人格分别绑定模型；Eunoia 不提供 API Key 或免费额度。
- 认知画像：十维、可追溯、可修正；用户可确认、编辑、导出或关闭更新。

首页提供六个人格入口。点击人格后才进入对应页面，发送首条消息时才创建对话；Haven 从侧栏单独进入。

## 快速开始

在 Windows 10/11 上安装 Python 3.11+ 和 Node.js 20+，运行 `start.bat`，打开 [http://127.0.0.1:6081](http://127.0.0.1:6081)。首次使用先在「模型管理」中添加自己的 API 配置或 Ollama 模型。

聊天、记忆、知识库和加密后的 API Key 默认保存在本机。使用云端模型时，请求所需内容会发送给你配置的服务商，费用由服务商向你收取。当前版本面向本机单用户使用。
