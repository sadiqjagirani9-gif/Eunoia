# Eunoia 使用与配置说明

本地优先的 AI 交流客户端。首页呈现六个独立人格空间；另有与画像和人格协作隔离的 Haven 倾听空间。Haven 支持倾听、安慰、陪伴和用户明确要求时的情绪宣泄，也会拒绝威胁、暴力和现实报复。Eunoia 不提供模型额度或预置 API Key：你可以接入自己选择的云端 API，也可以使用本机 Ollama。聊天记录、记忆、模型配置和知识库默认保存在自己的设备上。

## 功能

- 六个独立人格空间：Evelyn（情感解剖）、Arthur（理性辩论）、Sophia（生活指导）、Iris（自我探索）、Lucien（文学艺术）和 Felix（日常闲谈）。
- 独立的 Haven 倾听空间：优先倾听与支持，不读取六人格记忆，也不参与认知画像或联合会诊。
- 用户自带模型：OpenAI Compatible、Anthropic Messages、Ollama 和自定义服务商；人格可独立绑定模型。
- 模型管理：安全保存密钥、连接测试、全局默认模型、每人格参数和本地调用用量统计。
- 本地 SQLite 历史对话、用户可管理的长期记忆与认知画像。
- 按人格隔离的本地知识库检索；支持 PDF、TXT、Markdown 和公开 HTTPS 网页导入。
- Windows 一键启动脚本。

## 首页与对话

打开 Eunoia 后，首页显示六个人格入口。点击人格空间才进入该人格的欢迎页与输入框；进入空间本身不会创建对话，发送首条消息时才创建会话。左上角 Eunoia 标识可返回首页。Haven 从侧栏的「倾听空间」单独进入，其记忆与隐私面板可折叠。

## 人格隔离与联合会诊

六个人格分别加载独立版本的系统提示词，并按会话归属读取自己的聊天历史、长期记忆、认知观察、知识库及模型绑定。切换空间不会把上一人格的对话或私人分析带入下一人格。检索资料、导入文档和历史内容都作为参考数据处理，不能修改人格身份或权限。

「联合会诊」仅在用户主动选择参与人格并提交问题时运行。各人格分别调用自己的模型和知识库；会诊结果不会自动写入普通聊天或长期记忆。双视角分析会分别调用 Evelyn 与 Arthur，并分别使用各自已确认的认知观察。

数据库升级会在迁移前保存本地备份，已有对话按所属空间归档。无法从会话追溯归属的旧图谱和分析记录保留为 `unassigned`，不会自动分配给某个人格。当前版本为本机单用户模式，使用固定的 `local` 用户标识；若要部署为公网多用户服务，还需要增加身份认证、数据隔离和访问控制。

## 倾听空间

「倾听空间」是独立的 Haven 对话入口。进入后在「记忆与隐私」中选择自己已接入的模型；Haven 的模型绑定、对话和手动保存的记忆与六人格分开。Haven 只在用户明确进行吐槽、反击、讽刺、接梗等语言任务时，检索自己的 `haven` 语言资料命名空间；资料只是参考文本，不能覆盖人格、安全和隐私规则。Haven 不参与认知画像或联合会诊，也不自动提取长期记忆。Haven 记忆默认关闭；用户可逐条修改、删除，或清除全部倾听历史和记忆。需要把内容交给其他人格时，只能在具体一条自己发送的消息上选择接收人格，单次转交该条原文。选择云端模型会将本次对话、检索到的 Haven 资料和启用的 Haven 记忆发送给用户配置的服务商。当前运行模式为本机单用户模式，公网多用户部署需要先增加身份认证和权限隔离。

Haven 还包含一个独立的本地文本情绪分类器。它参考 [Multimodal-Emotion-Recognition](https://github.com/maelfabien/Multimodal-Emotion-Recognition) 的“文本预处理—特征表示—多标签概率输出”思路，但该仓库的 `02-Text` 实际识别英文 Big Five 人格特质，Eunoia 没有复用其人格模型或数据。当前实现使用中文字符 n-gram TF-IDF 与 One-vs-Rest Logistic Regression，在项目自带的公开表达示例上训练，输出悲伤、孤独、焦虑、愤怒、失望等候选情绪和置信度。结果只用于选择倾听语气和安慰资料，不是诊断、事实或用户画像，也不会写入数据库。安装依赖后可通过 `/api/listening/emotion-model` 查看模型元数据；没有 scikit-learn、禁用 `EUNOIA_EMOTION_CLASSIFIER=off` 或模型异常时，会降级到本地关键词提示，仍不影响对话。原仓库采用 Apache License 2.0，Eunoia 只复用公开方法思路并保留来源说明。

## 我的认知画像

从左侧「我的认知画像」进入十维画像：个人背景、思维、情绪、行为、价值观、认知盲点、人际、决策、自我认知和成长。首页显示已确认与待确认数量、资料覆盖的维度及最近更新。覆盖数量表示资料多少，不代表分析准确率。

对话完成后，系统只从明确的第一人称表达中提取少量原话线索。单次表达保持“情境观察”；同一线索经过不同会话、至少一周的重复支持后，才标记为“重复观察”，仍需用户确认。六人格的观察保留各自归属；统一画像只在用户打开画像时汇总，普通聊天不会读取其他人格的私人观察。在「隐私与控制」中可逐一授权人格读取用户自行填写并确认的统一画像条目，默认全部关闭；这不会共享其他人格的私人观察、记忆或对话。使用云端模型时，授权条目会随该人格的请求发送给用户配置的服务商。旧版六维记录会映射到新维度，原记录和证据不删除。

在画像页可逐条查看原话证据、确认、部分确认、拒绝、编辑或删除，也可主动添加已确认的个人信息，并区分明确背景与主观自评。拒绝的推测会进入本地抑制记录，减少换个维度再次生成相近判断。可排除指定话题、暂停自动更新、关闭认知分析、导出与恢复数据、清空全部认知画像。清空画像不删除聊天和普通长期记忆。

「成长时间轴」可保存并比较画像版本。「完整报告」先生成只依赖已确认原话的本地证据报告；没有资料的维度会显示信息不足。可主动选择已绑定模型生成更深入的综合，届时确认过的观察和证据会发送给该模型服务，且可能产生服务商费用。模型分析与主动探索结果都不会自动写入画像。数据库升至认知迁移 v6 前会创建 `pre-cognitive-v6-backup` SQLite 备份。

## Windows 快速开始

需要 Windows 10/11、Python 3.11+ 和 Node.js 20+。运行 `start.bat`，脚本会准备本地依赖并启动前后端。浏览器打开 [http://127.0.0.1:6081](http://127.0.0.1:6081)。首次启动安装依赖需要网络。

数据默认存放在 `%LOCALAPPDATA%\Eunoia`。可通过 `EUNOIA_DATA_DIR` 修改位置；可选环境变量见 `.env.example`。后端仅绑定本机回环地址。

## 配置模型

首次打开后选择「模型管理」并添加配置。Eunoia 不提供 API Key、免费额度或开发者代理。

**云端 API：**在所选服务商控制台申请 API Key，在模型管理中选服务商模板，按其当前文档填写 Base URL、协议和模型 ID。模板不会锁定模型列表。远程地址必须使用 HTTPS。连接测试提示很短，但服务商仍可能计费。云端模式会将该次请求所需的对话上下文发送给你配置的服务商，费用依其账单结算。

**Ollama 本地模型：**安装 Ollama 后，在 PowerShell 运行 `ollama pull qwen2.5:7b`，用 `ollama list` 查看模型 ID。添加「Ollama 本地」配置，Base URL 填 `http://127.0.0.1:11434`，协议选 Ollama，模型 ID 填列表中的名称；API Key 留空。保存后测试连接。

模型密钥只保存在后端，Windows 使用 DPAPI 加密；其他支持平台使用本地 Fernet 密钥文件。配置 API 不会返回已保存的密钥。删除模型配置会解除人格绑定并删除关联密钥。费用统计按用户填写的单价和接口返回的 Token 用量进行本地估算，不代表服务商真实账单。

## 数据与隐私

Eunoia 没有开发者托管的模型代理。选择云端模型时，请只配置可信服务商并查看其数据处理政策；选择本地 Ollama 模型时，请确认该模型为本地模型。SQLite 数据、知识库文件和记忆默认留在本机。API Key 不应提交到 GitHub；`.env`、数据库和运行数据已列入 `.gitignore`，`.env.example` 不包含密钥。

认知画像会记录带来源和可信度的可修正观察，用户可以查看、编辑、删除、导出或关闭认知分析。该工具不提供精神疾病诊断，也不替代专业心理支持。

## 知识库

六个人格的知识库按空间隔离，检索结果作为回答上下文，不跨人格默认混用。Haven 有两个独立命名空间：`knowledge_base/haven/<module>/` 的 12 模块中文语言风格库，以及 `knowledge_base/haven_emotional_support/<module>/` 的 15 模块情感安慰与支持库。前者覆盖修辞、阴阳怪气、毒舌、逻辑反击和情绪宣泄；后者覆盖情绪理解、悲伤/孤独/焦虑支持、共情、接纳、陪伴、失去、存在性困惑、压力缓解和危机边界。每份资料旁有 `.meta.json` 来源记录；知识库管理中的人格下拉框可分别查看、导入、编辑、删除和重建两套 Haven 资料。Haven 根据用户需求动态选择：吐槽和反击优先语言库，安慰和陪伴优先支持库，混合需求可以同时使用；普通闲聊不强制检索。来源元数据记录作者/机构、链接、版本、许可和摘要；未经许可不复制受版权保护的完整作品。语义索引可使用本地 Ollama Embedding 模型 `nomic-embed-text`，安装后在知识库页面重建索引；没有向量模型时使用本地词项检索。Haven 资料不会进入六人格模型、记忆、画像或会诊。
