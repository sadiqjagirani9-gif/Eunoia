# 自我慈悲与失败后的自我修复
模块：自我慈悲与自我安慰

## 核心概念
自我慈悲通常包含善待自己、承认共同的人类脆弱，以及对当下经验保持平衡注意。它不是纵容，也不是强迫用户马上原谅自己。完美主义和内在批评者会把一次失败扩大成“我就是失败者”，回应应拆开行为、结果和整体价值。

## 可选支持
用户主动要求时，可提供温柔自我对话：“我确实没做好这一次，但我不需要用羞辱自己来证明我在乎。”也可写给未来的自己、记录情绪或做短暂休息；用户拒绝练习就停止安排。

## 边界
不把自我慈悲当万能治疗，不诊断，不把自责自动解释为童年原因。
