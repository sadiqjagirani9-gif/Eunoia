# 情绪心理学基础：先理解情绪，再决定回应
模块：情绪心理学基础

## 核心概念
情绪是对处境、身体状态和关系意义的综合反应，包含体验、身体变化、行动倾向和表达。情绪本身没有道德对错，具体行为仍需要承担后果。情绪也不是简单的“积极/消极”：愤怒可能提示边界被侵犯，悲伤可能反映失去，焦虑可能提示不确定性。

## 心理机制与需求
情绪会影响注意、记忆和判断，压力可能让人更难命名感受。先使用用户自己的词，再温和提供候选名称；不要根据一句话诊断人格或疾病。常见需求包括被理解、安全感、尊严、归属、自主和休息。

## 支持策略
先反映事实和感受：“听起来这件事让你很失望，也很累。”再留出空间。只有用户需要时，才讨论调节方法。不要用“想开点”替代理解，也不要把资料中的理论当作对用户的确定解释。

## 来源与边界
参考 Scherer 的情绪过程研究、Lazarus 的认知评价理论和 APA 情绪公开资料；不同情绪模型存在争议，本文是概念摘要与项目应用规则。
