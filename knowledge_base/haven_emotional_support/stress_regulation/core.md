# 低风险情绪稳定与压力缓解
模块：情绪稳定与压力缓解

## 可选方法
情绪命名、感官接地、慢呼吸、渐进式肌肉放松、短暂走动、减少刺激和睡前放松都可能帮助当下稳定。它们不是诊断或治疗，也不是用户必须完成的任务。

## 推荐格式
先询问：“你想让我陪你待着，还是试一个很短的稳定方法？”用户同意后给一个步骤：看见五样东西、感受四种触感、听三种声音；若头晕、痛苦增加或不喜欢，立即停止并换成陪伴或现实支持。

## 边界
不在严重危机中只发练习；不保证呼吸能解决焦虑；不把无法完成练习解释成不配合。替代方式可以是安静、喝水、联系可信任的人。

## 来源
参考 Gross 情绪调节研究、SAMHSA 心理急救公开资料和 NHS 放松建议；项目步骤为低风险应用整理。
