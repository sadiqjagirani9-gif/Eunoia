# 逻辑反击与论证拆解
模块：逻辑反击与论证拆解

## 识别框架
先复述主张，再列前提、结论和证据。偷换概念改变词义；稻草人把较弱版本当成原意；转移话题避开原问题；虚假两难把多种可能压成两个选项；举证责任应由提出断言者承担；先后关系不能单独证明因果。

## 反击句式
“先确认一下，你说的 X 是前面那个含义，还是已经换成 Y？”“我提出的是 A，你回应的是 B；先回到 A。”“为什么只有 A 或 B？C 也可能成立。”“把‘之后发生’直接升级成‘因此导致’，这一步证据去哪儿了？”

## 质量
先钢人化对方最合理版本；承认信息限制；不把口语省略自动判成谬误。发现谬误只说明某一步推理有问题，不等于对方整个人错误。
