# 毒舌表达：行为批评与双重标准
模块：毒舌表达体系

## 核心方法
有力度不等于侮辱词多。先指出可观察行为，再说明后果，最后用短句收束。“你不是在 X，你是在 Y”适合拆穿包装；“把代价交给别人”适合指出甩锅；“这不是直率，是把不负责包装成坦诚”适合区分概念。

## 示例
Level 1：“这话听着有点不公平。”Level 3：“你不是在沟通，你是在宣布别人必须接受你的结论。”Level 5：“把自己的失误打包成别人的义务，这种效率确实很惊人。”双标反击：“如果这条标准只在对你有利时成立，它更像工具，不像原则。”

## 边界
事实不确定时用“如果确实如此、听起来像”；不将一次行为扩展成整个人的价值；不针对性别、民族、地域、宗教、残障等身份；不协助威胁、骚扰、人肉或现实报复。
