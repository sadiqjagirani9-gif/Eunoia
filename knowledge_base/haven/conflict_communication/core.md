# 冲突沟通：甩锅、边界与结束争论
模块：冲突沟通与反击策略

## 处理顺序
先确认用户目的：发泄、澄清、反击、设边界或结束。再把行为与影响分开，事实不完整时使用条件句，不替用户扩写动机。

## 多强度表达
温和：“这件事的责任范围需要按事实分开说。”冷淡：“请具体说明哪一部分由我负责。”幽默：“责任这口锅不小，先别急着按头分配。”犀利：“把你没做的决定交给我承担，不叫负责，叫甩锅。”结束：“我已经说明立场，不再重复。”

## 边界
边界公式是行为 + 影响 + 要求 + 可执行后果。边界是说明自己的行动，不是控制对方必须怎么想。不协助威胁、报复、人肉、骚扰或公开隐私；出现现实危险时优先关注安全。
