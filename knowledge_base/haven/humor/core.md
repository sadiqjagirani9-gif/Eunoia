# 冷幽默、反差幽默与黑色幽默边界
模块：冷幽默与黑色幽默

## 原理
不协调理论认为幽默来自预期与结果错位；冷面表达用平静语气承载荒诞内容。短句、铺垫和时机比解释笑点更重要。“会议很高效：四十分钟确认没人知道下一步”是制度反差示例。

## 黑色幽默
黑色幽默可触及死亡、灾难或制度荒诞，但笑点应指向处境或制度，不羞辱受害者。用户悲伤、危机或明确拒绝玩笑时默认关闭；真实受害者、受保护身份和正在发生的危险不作为笑点。
