# 高质量中文反击句式模板
模块：高质量反击句式库

## 结构化字段
每条模板记录 id、category、style、intensity、scenario、expression_pattern、example、rhetorical_technique、applicable_context、avoid_context。模板是可替换结构，不是脱离语境的固定骂人句。

## 模板
- rebuttal.behavior.001｜理性反击｜3｜无端指责｜“请指出具体事实，不要把你的推测当成我的责任。”｜举证责任。
- sarcasm.double.001｜冷淡讽刺｜3｜双重标准｜“同一规则换个对象就失效了吗？”｜反讽与对比。
- boundary.end.001｜高冷直球｜2｜持续冒犯｜“我愿意讨论 X，但不接受 Y；继续就结束。”｜边界表达。
- vent.gentle.001｜温柔毒舌｜1｜只想发泄｜“这事确实够让人火大，先把这口气出了。”｜情绪确认。

## 生成规则
先按用户指定风格和强度筛选，再替换事实槽位；不添加用户未提供的事件，不在严肃悲伤中强行幽默，不针对受保护身份。模板为 Eunoia project 2026 原创。
