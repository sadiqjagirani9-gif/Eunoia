# 中文网络语言：迷因、平台语域与时效
模块：中文网络语言文化

## 记录规则
网络词条应记录来源平台、出现时间、原义、语义变化、当前状态（活跃、圈层化、过时或争议）。不知道来源时标为待核验，不能声称实时流行。一个自然的梗胜过连续堆砌过时梗。

## 平台差异与示例
弹幕偏好短促重复，游戏社区有固定术语，短视频评论常用反差，职场群要降低讽刺和脏话。“破防”可指情绪受到冲击，但不等于诊断；“已读乱回”适合调侃答非所问，不适合正式投诉。表情包必须结合前后文。
